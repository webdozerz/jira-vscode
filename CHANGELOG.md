# Changelog

## 0.2.0

### Добавлено
- **Панель задачи** по клику: описание, комментарии, ворклоги, родитель, эпик, подзадачи, связи, вложения,
  спринты; кнопки «Комментарий», «Ворклог», «Статус» с формами прямо в панели.
- **Создание ветки из задачи** (`feat/SE-123` по умолчанию, шаблон настраивается), с предложением перевести
  задачу в «In progress».
- **Открыть задачу по ключу или ссылке**; ключ из буфера обмена подставляется автоматически.
- **Спринты**: фильтр (активные, без спринта, конкретный) и группировка дерева по спринтам.
- **Правка и удаление своих** комментариев и ворклогов.
- **Вложения**: открытие в VS Code или в браузере.
- **Markdown в комментариях**: конвертация в разметку Jira и предпросмотр средствами самой Jira;
  черновик комментария сохраняется.
- **Цепочка статусов**: после смены статуса сразу предлагаются следующие переходы.
- Одна кнопка в заголовке дерева сворачивает или разворачивает все группы; иконка меняется по состоянию.
- Иконка расширения, тесты (в том числе скрипта панели в jsdom).

### Изменено
- Ворклоги в панели загружаются полностью (раньше Jira отдавала не больше 20).

## 0.1.0

- Первая версия: токен, выбор проекта, дерево задач по статусам, фильтры «мои / все» и по статусам,
  комментарий, ворклог и смена статуса.
